## 占位图片生成
可以使用以下工具生成占位图片：
- https://via.placeholder.com/
- https://placehold.co/
- 或使用纯色背景 + 文字的图片

示例占位图片URL格式：
- https://via.placeholder.com/1920x600/0056b3/ffffff?text=专业连接器解决方案
- https://via.placeholder.com/800x600/4a90e2/ffffff?text=航空连接器
